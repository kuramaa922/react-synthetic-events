"Светофор" должен отображать три световых сигнала: красный, желтый и зеленый. Каждый световой сигнал представляет собой круг, который может быть активным (бэкграунд яркого цвета) или неактивным (бэкграунд тусклого цвета). Для активных сигналов в репозитории уже есть CSS-класс с постфиксом "–active". При первом рендере активным должен быть красный световой сигнал с установленным на нем фокусом.

<img width="1008" height="590" alt="image" src="https://github.com/user-attachments/assets/382f17b4-6dd3-4441-8c5b-69a6fda956fb" />

По клику мыши на круг должна происходить активация соответствующего светового сигнала. Также должна быть возможность переключаться между кругами при помощи клавиши Tab и активировать их по нажатию на Enter.

Учти, что активный световой сигнал всегда только один.

В проекте уже прописаны все необходимые стили. Для работы с классами ты можешь использовать библиотеки classnames или clsx.
